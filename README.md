# National Real Estate AVM Engine (SFA-AVM)

국토교통부 실거래 데이터를 기반으로 대한민국 전역의 단독/다가구 주택 가치를 산정하는 고성능 AVM(Automated Valuation Model) 엔진입니다. 본 프로젝트는 정교한 시점 보정과 하이브리드 머신러닝 아키텍처를 통해 부동산 가격 예측의 신뢰성을 극대화하는 데 중점을 두었습니다.

## 프로젝트 개요
*   **개발 목표**: 전국 단독/다가구 주택의 거래 사례를 분석하고, 시점 보정 기술을 적용하여 현재 가치에 근접한 예측 모델 구축
*   **핵심 지표**: **R2 Score 0.8701**, **MAPE 36.95%**
*   **데이터 소스**: 국토교통부 실거래가 공개시스템 (API), 한국부동산원 지가변동률 지수

---

## 데이터 파이프라인
데이터 수집부터 모델 학습까지의 전 과정을 자동화 및 고도화하였습니다.

*   **병렬 데이터 수집**: `ThreadPoolExecutor`를 활용하여 전국 250여 개 시군구 데이터를 병렬로 수집하며, API 호출 한도(429 Error)를 고려한 재시작(Resume) 로직을 포함합니다.
*   **시점 보정 (Time Correction)**: 가격 데이터의 시계열적 노이즈를 제거하기 위해 모든 과거 거래 데이터를 2026년 1월 시점의 지수로 환산 및 보정하였습니다.
*   **품질 관리 (Data Trimming)**: 상/하위 1.5%의 가격 아웃라이어를 제거하여 자산 가치의 왜곡을 방지하고 모델의 일반화 성능을 높였습니다.

## 주요 피처 엔지니어링
예측 성능에 기여도가 높은 핵심 변수들을 도메인 지식 기반으로 생성하였습니다.

### 피처 중요도 (Feature Importance)
| 순위 | 피처명 | 기여 점수 | 설명 |
| :--- | :--- | :--- | :--- |
| 1 | **buildYear** | 0.382 | 건물 노후도가 가격 결정의 가장 큰 요인임 |
| 2 | **floor_area_ratio** | 0.215 | 대지 대비 연면적 비율 (용적률 지표) |
| 3 | **spatial_block_id_str** | 0.147 | 미시적 입지 정보 (지번 기반 블록 ID) |
| 4 | **umd_old_building_ratio** | 0.098 | 해당 지역 내 노후 건축물 밀집 정도 |
| 5 | **Age** | 0.082 | 건물 연식 |

## 모델 아키텍처 및 성능
트리 기반 앙상블과 신경망(TabNet)을 결합한 하이브리드 구조를 채택하였습니다.

### 모델별 성능 대비 (Numerical Scorecard)
| 모델 유형 | R2 Score | MAE (원/㎡) | MAPE (%) |
| :--- | :---: | :---: | :---: |
| **XGBoost (Tuned)** | **0.8701** | 463,073 | 38.27 |
| **LightGBM (Tuned)** | 0.8691 | 467,666 | 38.61 |
| **CatBoost (Tuned)** | 0.8637 | 478,144 | 39.21 |
| **Ensemble (R2-Weighted)** | 0.8676 | **463,412** | **36.95** |

*   **앙상블 전략**: 개별 모델의 예측값에 R2 성능 기반 가중치를 부여하여 스택킹 앙상블을 구현함으로써 오차율(MAPE)을 단일 모델 대비 1.3%p 추가 개선하였습니다.

## 지번 마스킹 대응 및 복구 계획
실거래가 공개시스템의 지번 마스킹(예: 25-**)으로 인한 공간 정보 손실에 대응하는 전략입니다.

1.  **현 상태 (Status Quo)**: 법정동 코드와 마스킹된 지번 유니크 값을 결합한 `spatial_block_id`를 생성하여 동일 블록 내의 거래를 군집화함.
2.  **복구 계획 (Recovery Plan)**:
    *   **좌표 변환**: 카카오/네이버 지도 API의 역지오코딩을 활용하여 특정 법정동 내 거래 사례들의 중심 좌표 추산 및 클러스터링.
    *   **공시지가 매핑**: 표준지 공시지가 데이터를 매핑하여 마스킹된 번지의 정확한 위치적 가치를 대리 변수화하여 보완할 예정.

## 트러블슈팅
개발 과정에서 발생한 주요 이슈와 해결 방안입니다.

*   **API 429 Quota Exceeded**: 수십만 건의 전국 데이터 수집 시 발생하는 API 한도 문제를 해결하기 위해 오프셋을 파일로 저장하고, 실패한 지역부터 자동 재시작하는 `ResumeCollector`를 구현함.
*   **PyTorch DLL Load Failed**: Windows 환경에서 TabNet 학습 시 발생한 라이브러리 충돌을 `torch-cpu` 전용 인덱스 재설치를 통해 해결함.
*   **LightGBM Callback Hang**: `early_stopping` 콜백과 `verbose=-1` 설정 간의 동기화 이슈를 `log_evaluation` 콜백 명시적 도입으로 해결하여 안정적 학습 환경을 구축함.

## 결론 및 향후 과제
본 엔진은 내부 데이터의 시계열 보정과 공간 블록 엔지니어링을 통해 단독 모델로서 87% 이상의 높은 신뢰도를 확보했습니다. 향후 실제 지하철역 좌표 데이터 및 학군 밀집도 등 외부 공간 피처를 결합하여 MAPE를 30% 이하로 낮추는 고도화 작업을 진행할 예정입니다.
